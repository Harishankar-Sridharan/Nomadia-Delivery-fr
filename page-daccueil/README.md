# Page d’accueil

Utilisez les pages de cette section pour comprendre et configurer la page d’accueil de Nomadia Delivery.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery**. L’écran d’accueil est la page d’arrivée par défaut.
* Ouvrez l’**icône de compte** dans le coin supérieur droit de la page d’accueil pour accéder à **Mes préférences**.

## Présentation de la fonctionnalité

* **Comprendre l’écran d’accueil** : explique les principales zones de l’écran d’accueil, telles que les onglets de navigation, Mes KPI et Statistiques des missions.
* **Configurer l’affichage des statuts des missions** : sélectionnez jusqu’à cinq statuts de mission à afficher sur la page d’accueil.
* **Configurer l’affichage de mes KPI** : choisissez le tableau de bord et une période de calcul allant du dernier jour aux sept derniers jours.
* **Actualiser la date des KPI et les statuts des missions** : actualisez manuellement les KPI et les statistiques de la page d’accueil.

## Conseils

{% hint style="info" %}
**Centrez votre affichage** : sélectionnez les statuts et le tableau de bord les plus pertinents pour vos besoins opérationnels afin de rester concentré et efficace.
{% endhint %}

{% hint style="warning" %}
**Limite de statuts** : vous pouvez afficher jusqu’à cinq statuts de mission sur la page d’accueil.
