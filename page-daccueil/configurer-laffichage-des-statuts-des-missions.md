# Configurer l’affichage des statuts des missions

Cette fonctionnalité permet aux utilisateurs de personnaliser les statuts de mission affichés sur le tableau de bord de leur page d’accueil. En sélectionnant jusqu’à cinq statuts, les utilisateurs peuvent adapter l’affichage pour montrer les informations les plus pertinentes en fonction de leurs besoins opérationnels, ce qui les aide à rester concentrés et efficaces.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** et ouvrez la **page d’accueil**.

## Présentation de la fonctionnalité

* **Icône de compte** : située dans le coin supérieur droit de l’écran ; ouvre le menu déroulant.
* **Mes préférences** : l’option dans laquelle vous choisissez les statuts des statistiques de mission.
* **Statuts des statistiques de mission** : **Créée, Chargée, Livrée, Non livrée et Enlèvement**, dont vous pouvez choisir jusqu’à cinq.

## Configurer l’affichage des statuts des missions

1. Depuis la **page d’accueil**, cliquez sur l’**icône de compte** située dans le coin supérieur droit de l’écran.
2. Dans le menu déroulant, sélectionnez **Mes préférences**.
3. Choisissez jusqu’à cinq statuts des statistiques de mission à afficher sur la page d’accueil parmi les options suivantes : **Créée, Chargée, Livrée, Non livrée et Enlèvement**.
4. Après avoir sélectionné les statuts souhaités, cliquez sur **Enregistrer**.

### Résultat

Votre page d’accueil affiche les KPI sélectionnés.

## Conseils

{% hint style="info" %}
**Centrez votre affichage** : sélectionnez les statuts les plus pertinents pour vos besoins opérationnels afin de rester concentré et efficace.
{% endhint %}

{% hint style="warning" %}
**Limite de statuts** : choisissez jusqu’à cinq statuts à afficher sur la page d’accueil.
{% endhint %}
