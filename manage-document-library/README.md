# Gérer la bibliothèque de documents

La fonctionnalité Gérer la bibliothèque de documents fournit un référentiel centralisé pour stocker, organiser et distribuer les documents couramment utilisés au sein de l’organisation de livraison. Elle garantit un accès rapide aux documents de référence tels que les consignes de sécurité, les directives de conformité, les procédures d’exploitation et les manuels de formation, tant pour le personnel du Backoffice que pour les agents sur le terrain.

## Avant de commencer

* Assurez-vous que votre fichier est dans l’un de ces formats pris en charge : XLSX, DOCX, PDF, JPG ou PNG.

## Présentation de la fonctionnalité

* **Bibliothèque de documents** : stocke les documents couramment utilisés tels que les consignes de sécurité, les directives de conformité, les procédures d’exploitation et les manuels de formation, pour le personnel du Backoffice et les agents sur le terrain.
* **Parcourir l’ordinateur** : téléverse un fichier depuis votre système local dans la bibliothèque.
* **Gérer les documents de mission** : couvre l’importation, le téléversement, le téléchargement et la suppression des documents de mission.
* **Recommandations de documents** : garantit que les documents requis sont disponibles pour chaque expédition internationale.
* **Ajout de documents à la mission** : lie à une mission des documents provenant de la bibliothèque, de votre ordinateur ou d’un stockage cloud.

## Importer un document dans la bibliothèque

1. Allez dans **Configuration**.
2. Cliquez sur le **menu Configuration**.
3. Sous **Mes données**, cliquez sur **Bibliothèque de documents**.

<figure><img src="../.gitbook/assets/image (69) (1).png" alt=""><figcaption></figcaption></figure>

4. Cliquez sur **Parcourir l’ordinateur** pour téléverser le fichier.

<figure><img src="../.gitbook/assets/image (70) (1).png" alt=""><figcaption></figcaption></figure>

5. Sélectionnez un fichier valide depuis un système local.

### Résultat

Les documents sont importés avec succès.
