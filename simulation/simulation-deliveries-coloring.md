# Colorer les livraisons

Cette page explique comment utiliser **Coloration** pour appliquer des règles de couleur aux livraisons.

## Quand l’utiliser

Utilisez **Coloration** pour attribuer une couleur aux livraisons selon une règle, par exemple une couleur par livreur. Les couleurs permettent de voir plus facilement quelles livraisons vont ensemble.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Livraisons**.
2. Cliquez sur la flèche déroulante **Livraisons**, puis cliquez sur **Coloration**.
3. Dans la fenêtre **Couleur des livraisons**, consultez les règles. Chaque ligne est une règle comportant une condition, par exemple **Affectée à = "Deliverer-James"**, et une couleur.
4. Cochez la case au début d’une règle pour l’utiliser.
5. Pour modifier la condition d’une règle, modifiez la condition dans la ligne, ou saisissez dans **Poursuivez votre filtre**.
6. Pour supprimer une règle, cliquez sur l’icône de corbeille à la fin de la ligne.
7. Pour créer une règle, cliquez sur **Ajouter**.
8. Pour afficher également les couleurs dans le planning, activez **Appliquer la coloration dans le planning**.
9. Cliquez sur **Enregistrer**.

Cliquez sur **Annuler** pour fermer la fenêtre sans enregistrer.

![La fenêtre Couleur des livraisons avec une règle par livreur](../.gitbook/assets/Simulation_DeliveriesColoring_001.jpg)

## Options et champs

| Option ou champ | Ce que cela fait | Remarques |
|---|---|---|
| **Appliquer la coloration dans le planning** | Affiche les couleurs dans le planning. | Le commutateur affiche **Non** par défaut. |
| Case à cocher de la règle | Active ou désactive une règle. | Seules les règles sélectionnées colorent les livraisons. |
| Condition de la règle | Définit quelles livraisons reçoivent la couleur, par exemple **Affectée à = "Deliverer-John"**. | Ajoutez d’autres conditions dans **Poursuivez votre filtre**. |
| Pastille de couleur | Affiche la couleur de la règle. | |
| Icône de corbeille | Supprime la règle. | |
| **Ajouter** | Ajoute une nouvelle règle. | |
| **Enregistrer** | Enregistre les règles. | |
| **Annuler** | Ferme la fenêtre sans enregistrer. | |

## Résultat

Les livraisons qui correspondent à une règle sélectionnée reçoivent la couleur de cette règle.
