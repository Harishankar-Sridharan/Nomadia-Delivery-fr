# Graphiques d’analyse

Cette page explique ce que montre chaque graphique du panneau **Analyse**.

## Avant de commencer

* Ajoutez le panneau **Analyse** à la page. Voir [Analyser les résultats](simulation-analysis.md).

## Étapes

1. Cliquez sur la flèche de la liste déroulante **Analyse**.
2. Cliquez sur l’un des graphiques suivants :
   * **Comparaison de la disponibilité des véhicules avec le cumul des durées de livraison (planifiées/non planifiées)** : compare la disponibilité des véhicules avec le total des durées de livraison, pour les livraisons planifiées et non planifiées.
   * **Nombre de livraisons par durée** : indique le nombre de livraisons pour chaque durée.
   * **Somme par durée de livraison** : indique la somme pour chaque durée de livraison.
   * **Nombre de fréquences de livraison** : indique le nombre de livraisons pour chaque fréquence.
   * **Nombre de livraisons par plage horaire** : indique le nombre de livraisons pour chaque plage horaire.
   * **Nombre de livraisons par ville** : indique le nombre de livraisons dans chaque ville.
   * **Nombre de livraisons par territoire** : indique le nombre de livraisons dans chaque territoire.
   * **Taux d’utilisation par véhicule** : indique dans quelle mesure chaque véhicule est utilisé.

## Résultat

Le panneau affiche le graphique que vous avez sélectionné. Les graphiques montrent les **Livraisons planifiées** et les **Livraisons non planifiées** dans des couleurs différentes.
