# Verrouiller et déverrouiller des livraisons

Cette page explique comment verrouiller des livraisons pour les conserver telles quelles, et comment les déverrouiller à nouveau.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Livraisons**.
2. Cochez les cases des livraisons que vous souhaitez verrouiller ou déverrouiller.
3. Cliquez sur la flèche déroulante **Livraisons**.
4. Cliquez sur **Verrouiller** pour verrouiller les livraisons, ou sur **Déverrouiller** pour les déverrouiller.

## Résultat

La colonne **Verrouillée** du panneau **Livraisons** indique si une livraison est verrouillée.

## Conseils

{% hint style="info" %}
**Itinéraires verrouillés** : certaines actions, comme **Ordonnancement sur un seul itinéraire**, n’ont aucun effet lorsqu’elles ne concernent que des itinéraires verrouillés.
{% endhint %}
