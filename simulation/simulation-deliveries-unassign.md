# Désaffecter des livraisons

Cette page explique comment retirer les livraisons sélectionnées des itinéraires auxquels elles sont affectées.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Livraisons**.
2. Cochez les cases des livraisons que vous souhaitez désaffecter.
3. Cliquez sur la flèche déroulante **Livraisons**, puis cliquez sur **Désaffecter**.

## Résultat

Vous pouvez vérifier les livraisons dans les colonnes **Planifiée** et **Affectée à** du panneau **Livraisons**.
