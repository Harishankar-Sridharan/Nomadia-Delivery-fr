# Valider les itinéraires

Cette page explique comment valider les itinéraires que vous souhaitez utiliser.

## Quand l’utiliser

Validez les itinéraires lorsque le plan vous convient. La validation envoie les itinéraires aux livreurs. Enregistrez d’abord la simulation, puis validez les itinéraires.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Itinéraires**.
2. Cochez les cases des itinéraires que vous souhaitez valider.
3. Cliquez sur la flèche de la liste déroulante **Itinéraires**, puis cliquez sur **Valider**.

Vous pouvez également cliquer sur **Valider les itinéraires** dans la fenêtre **Résultats de l’optimisation**.

## Résultat

Les itinéraires validés apparaissent dans le panneau **Itinéraires validés**, avec leur **Itinéraire**, leur **Date** et leur **Livreur**. Voir [Afficher les itinéraires validés](simulation-validated-routes.md).
