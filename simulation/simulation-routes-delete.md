# Supprimer des itinéraires

Cette page explique comment retirer les itinéraires sélectionnés de la simulation.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Itinéraires**.
2. Cochez les cases des itinéraires que vous souhaitez supprimer.
3. Cliquez sur la flèche déroulante **Itinéraires**, puis cliquez sur **Supprimer**.

## Résultat

Les itinéraires sont retirés de la liste du panneau **Itinéraires**.

## Conseils

{% hint style="info" %}
**Conservez vos modifications** : cliquez sur **Enregistrer les modifications** dans la barre d’outils pour conserver les modifications apportées à la simulation.
{% endhint %}
