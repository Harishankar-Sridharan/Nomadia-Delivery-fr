# Désaffecter des itinéraires

Cette page explique comment supprimer l’affectation des itinéraires sélectionnés.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Itinéraires**.
2. Cochez les cases des itinéraires que vous souhaitez désaffecter.
3. Cliquez sur la flèche déroulante **Itinéraires**, puis cliquez sur **Désaffecter**.

## Résultat

Vous pouvez vérifier le résultat dans la colonne **Utilisateur mobile** du panneau **Itinéraires**.
