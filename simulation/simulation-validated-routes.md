# Consulter les itinéraires validés

Cette page explique comment afficher le panneau **Itinéraires validés** pour voir les itinéraires que vous avez validés.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).
* Validez au moins un itinéraire. Voir [Valider les itinéraires](simulation-routes-validate.md).

## Étapes

1. Accédez à **Simulation**.
2. Cliquez sur **Modifier l’affichage des panneaux**.
3. Faites glisser **Itinéraires validés** sur la page.
4. Cliquez sur l’icône de liste pour voir les itinéraires sous forme de liste, ou sur l’icône Gantt pour les voir sur une chronologie.

![Le panneau Itinéraires validés avec les colonnes Itinéraire, Date et Livreur](../.gitbook/assets/Simulation_ValidatedRoutes_001.png)

## Résultat

Le panneau affiche chaque itinéraire validé avec son **Itinéraire**, sa **Date** et son **Livreur**. La liste est vide lorsqu’aucun itinéraire n’est validé.

## Conseils

{% hint style="info" %}
**Passer d’un panneau à l’autre** : lorsque vous ajoutez plusieurs panneaux au même endroit, cliquez sur le nom du panneau en haut à droite, par exemple **Itinéraires validés** ou **Analyse**, pour passer de l’un à l’autre.
{% endhint %}
