# Affecter des itinéraires

Cette page explique comment affecter les itinéraires sélectionnés.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Itinéraires**.
2. Cochez les cases des itinéraires que vous souhaitez affecter.
3. Cliquez sur la flèche déroulante **Itinéraires**, puis cliquez sur **Affecter**.

Vous pouvez également sélectionner un livreur pour un itinéraire directement dans la liste **Utilisateur mobile** de l’itinéraire.

## Résultat

Vous pouvez vérifier l’affectation dans la colonne **Utilisateur mobile** du panneau **Itinéraires**.
