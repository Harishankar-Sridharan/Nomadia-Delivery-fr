# Gérer les modèles de documents

**Gérer les modèles pour les documents de mission**

La fonctionnalité Gérer les modèles de documents permet aux administrateurs et aux utilisateurs du Backoffice de créer, configurer et maintenir des modèles réutilisables pour des documents tels que les bordereaux de livraison, les factures, les preuves de livraison et les rapports de tâche. Ces modèles standardisent la documentation dans l’ensemble des opérations et garantissent la cohérence de l’image de marque, de la structure et des informations requises. Vous pouvez concevoir vos propres modèles pour remplacer le modèle par défaut.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à la page **Configuration**.
* Ouvrez **Configuration**, cliquez sur **Menu Configuration**, puis sous **Personnalisation**, cliquez sur **Modèles de documents**.
* Pour importer un modèle, disposez d’un fichier valide sur votre système local.

## Télécharger un modèle de document

1. Allez dans **Configuration**.
2. Cliquez sur **Menu Configuration**.
3. Sous **Personnalisation**, cliquez sur **Modèles de documents**.
4. Sélectionnez le document souhaité dans la liste.

<figure><img src="../.gitbook/assets/image (45) (1) (1)_fr.png" alt=""><figcaption></figcaption></figure>

5. Cliquez sur le menu déroulant **Actions**.
6. Cliquez sur **Télécharger**.

<figure><img src="../.gitbook/assets/image (46) (1) (1)_fr.png" alt=""><figcaption></figcaption></figure>

### Résultat

Les modèles de documents sont téléchargés avec succès.

## Conseils

{% hint style="info" %}
**Remplacer le modèle par défaut** : vous pouvez concevoir vos propres modèles pour remplacer le modèle par défaut, ce qui garantit la cohérence de l’image de marque, de la structure et des informations requises dans l’ensemble des opérations.
{% endhint %}

{% hint style="warning" %}
**Modèles par défaut** : les modèles par défaut sont activés par défaut et ne peuvent ni être désactivés, ni modifiés, ni supprimés. Pour en personnaliser un, téléchargez-le et modifiez la copie, comme décrit dans [Personnalisation des modèles Word](customizing-word-templates.md).
{% endhint %}
