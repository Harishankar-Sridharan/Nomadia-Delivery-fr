# Gérer les études et les zones

Utilisez Gérer les études et les zones pour travailler avec les zones postales et la sectorisation.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à l’onglet **Configuration**.
* Ouvrez l’onglet **Configuration** et cliquez sur **Gérer les études et les zones** pour afficher les missions et les études disponibles.

## Présentation de la fonctionnalité

* **Gérer les zones postales** : permet aux administrateurs et aux responsables logistiques de définir et de gérer des zones de livraison géographiques en fonction des codes postaux.
* **Créer des zones postales par gestion territoriale (sectorisation)** : génère automatiquement des secteurs, en équilibrant les territoires selon les règles que vous définissez et en les alignant sur les limites des codes postaux.
* **Personnaliser le tableau des zones** : vous permet de choisir les champs affichés pour les zones d’une mission.

## Conseils

{% hint style="info" %}
**Préfixe du code postal** : le préfixe standardise les codes postaux à une longueur fixe de 6 chiffres ; définissez-le donc lorsque vous ajoutez une zone postale.
{% endhint %}

{% hint style="warning" %}
**Données des codes postaux** : les données des limites de code postal ne sont pas disponibles pour certains pays, ce qui affecte la sectorisation alignée sur les limites des codes postaux.
{% endhint %}
