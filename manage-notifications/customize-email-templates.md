# Personnaliser les modèles d’e-mail

Dans Nomadia Delivery, les modèles d’e-mail personnalisés permettent aux planificateurs de personnaliser la communication avec les clients finaux en fonction de paramètres de mission tels que le type de client ou la valeur du colis. Cette fonctionnalité améliore la transparence opérationnelle et renforce la satisfaction client en garantissant l’envoi de messages pertinents et en temps voulu.

## Avant de commencer

Pour simplifier l’intégration, Nomadia Delivery propose une collection de modèles par défaut préconfigurés pour les e-mails et les SMS :

* Ces modèles sont activés par défaut.
* Ils servent de solution de repli lorsqu’aucune configuration personnalisée n’est en place.
* Bien qu’ils ne puissent pas être supprimés, ils peuvent être désactivés si nécessaire.

![](<../.gitbook/assets/image-33 (4).png>)

## Présentation de la fonctionnalité

* **Modèles par défaut** : modèles d’e-mail et de SMS préconfigurés, activés par défaut, qui servent de solution de repli lorsqu’aucune configuration personnalisée n’est en place.
* **Configurer les messages sortants** : l’entrée du menu **Configuration** dans laquelle vous gérez les modèles de messages.
* Onglet **Modèles d’e-mail** : l’onglet dans lequel vous ajoutez et gérez les modèles de notification par e-mail.
* **Actions** > **Ajouter** : vous permet de choisir l’un des modèles disponibles à personnaliser, par exemple **Fenêtre horaire pour communiquer**.
* **Type de configuration** : associe un modèle à la mission.

## Créer un modèle de notification par e-mail personnalisé

1. Ouvrez l’application Nomadia Delivery et accédez à l’onglet **Configuration**.
2. Dans le menu déroulant, sélectionnez **Configurer les messages sortants**.
3. Cliquez sur l’onglet **Modèles d’e-mail**.

![](<../.gitbook/assets/image-34 (4).png>)

4. Dans le tableau, cliquez sur le bouton **Actions** et sélectionnez **Ajouter**.

![](<../.gitbook/assets/image-35 (4).png>)

5. Choisissez l’un des modèles disponibles à personnaliser (par exemple, **Fenêtre horaire pour communiquer**).

![](<../.gitbook/assets/image-36 (4).png>)

6. Dans la fenêtre contextuelle, personnalisez et configurez le message selon vos besoins.
7. Sélectionnez un type de configuration pour associer le modèle à la mission.
8. Activez le modèle et enregistrez vos modifications.

![](<../.gitbook/assets/image-37 (4).png>)

Répétez le processus pour configurer d’autres notifications et les associer aux types de configuration appropriés.
