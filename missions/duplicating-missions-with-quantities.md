# Duplication des missions avec quantités

Les donneurs d’ordre et les transporteurs peuvent dupliquer des missions avec quantités dans Nomadia Delivery. Cette fonctionnalité simplifie la gestion de plusieurs articles, améliorant ainsi l’efficacité et la précision dans la gestion des missions.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à l’onglet **Missions**.
* Préparez les informations obligatoires de la mission selon son type, telles que l’agence, l’adresse de retrait et l’adresse de livraison.
* Préparez les détails du colis : longueur, largeur, hauteur, poids, volume et contraintes du solveur.

## Présentation de la fonctionnalité

* **Liste déroulante Actions** : ouvre le menu du tableau des missions dans lequel vous sélectionnez **Ajouter** pour lancer l’assistant de mission.
* **Section Colis** : contient les détails du colis, tels que la longueur, la largeur, la hauteur, le poids, le volume et les contraintes du solveur.
* **Symbole +** : ajoute un nouveau colis avec des valeurs différentes.
* **Icône Copier** : duplique un colis existant avec les mêmes détails.
* **Icône Supprimer** : supprime un colis ajouté par erreur.
* **Ajouter** : génère le nombre requis de missions après la finalisation des colis.

## Dupliquer des missions avec quantités

1. Ouvrez l’application Nomadia Delivery et accédez à l’onglet **Missions**.

<figure><img src="../.gitbook/assets/en-image (38).png" alt=""><figcaption></figcaption></figure>

2. Dans le tableau des missions, cliquez sur le **menu déroulant Actions** et sélectionnez **Ajouter**.

<figure><img src="../.gitbook/assets/en-image (39).png" alt=""><figcaption></figcaption></figure>

3. Dans l’assistant de mission, renseignez les champs obligatoires selon le type de mission **(par exemple : agence, adresse de retrait, adresse de livraison, etc.).**
4. Dans la section Colis, saisissez les détails du colis tels que **la longueur, la largeur, la hauteur, le poids, le volume** et **les contraintes du solveur**.

<figure><img src="../.gitbook/assets/en-image (41).png" alt=""><figcaption></figcaption></figure>

5. Pour ajouter un nouveau colis avec des valeurs différentes, cliquez sur le symbole **+**.

<figure><img src="../.gitbook/assets/en-image (42).png" alt=""><figcaption></figcaption></figure>

6. Pour dupliquer un colis existant avec les mêmes détails, cliquez sur l’icône **Copier**.

<figure><img src="../.gitbook/assets/en-image (43).png" alt=""><figcaption></figcaption></figure>

7. Si vous ajoutez un colis par erreur, cliquez sur l’icône **Supprimer** pour le supprimer.

<figure><img src="../.gitbook/assets/en-image (44).png" alt=""><figcaption></figcaption></figure>

8. Après avoir finalisé les colis à dupliquer, cliquez sur **Ajouter** pour générer le nombre requis de missions.

<figure><img src="../.gitbook/assets/en-image (45).png" alt=""><figcaption></figcaption></figure>

### Résultat

Les missions dupliquées apparaissent dans le tableau des missions.

<figure><img src="../.gitbook/assets/en-image (46).png" alt=""><figcaption></figcaption></figure>

## Conseils

{% hint style="info" %}
**Réutiliser les détails du colis** : pour ajouter un colis avec les mêmes détails, cliquez sur l’icône **Copier** au lieu de saisir à nouveau les valeurs. Cliquez sur le symbole **+** uniquement lorsque le nouveau colis a des valeurs différentes.
{% endhint %}

{% hint style="warning" %}
**Vérifier les colis avant d’ajouter** : finalisez les colis avant de cliquer sur **Ajouter**, car cette action génère le nombre requis de missions. Si vous ajoutez un colis par erreur, cliquez sur l’icône **Supprimer** pour le supprimer.
{% endhint %}
