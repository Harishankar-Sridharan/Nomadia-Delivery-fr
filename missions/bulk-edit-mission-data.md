# Modifier en masse les données de mission

L’édition en masse des données de mission permet des mises à jour à grande échelle des informations de mission, réduisant les efforts manuels et gagnant du temps en évitant les tâches répétitives. Cette fonctionnalité améliore l’efficacité tout en maintenant le contrôle et l’intégrité des données entre les équipes.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à la page **Missions**.
* Assurez-vous que les missions que vous souhaitez mettre à jour existent dans le tableau des missions.
* Décidez quels champs de mission et champs personnalisés vous souhaitez activer pour l’édition en masse.

## Présentation de la fonctionnalité

* **Page Missions** : page de l’en-tête principal où vous choisissez les missions à mettre à jour dans le tableau des missions.
* **Fenêtre contextuelle d’édition en masse** : fenêtre contextuelle où vous nommez la configuration, choisissez les champs et définissez les valeurs des missions sélectionnées.
* **Nom** : nom que vous saisissez pour la configuration d’édition en masse.
* **Bouton flèche** : déplace les champs sélectionnés vers la partie droite pour les activer pour l’édition en masse.
* **Champs personnalisés** : champs personnalisés que vous pouvez activer pour l’édition en masse de la même manière que les champs standard.
* **Enregistrer** : enregistre la configuration d’édition en masse ou applique les valeurs choisies aux missions sélectionnées.

## Créer une configuration d’édition en masse

1. Depuis l’en-tête principal, cliquez sur la page **Missions**.

<figure><img src="../.gitbook/assets/en-image (192)_fr.png" alt=""><figcaption></figcaption></figure>

2. Choisissez les missions qui vous intéressent dans le tableau des missions.

<figure><img src="../.gitbook/assets/en-image (193).png" alt=""><figcaption></figcaption></figure>

3. Saisissez un **Nom** pour la configuration d’édition en masse dans la fenêtre contextuelle d’édition en masse.

<figure><img src="../.gitbook/assets/en-image (194).png" alt=""><figcaption></figcaption></figure>

4. Sélectionnez les champs à activer pour l’édition en masse et utilisez le bouton flèche pour les déplacer vers la partie droite.

<figure><img src="../.gitbook/assets/en-image (214).png" alt=""><figcaption></figcaption></figure>

5. Répétez les mêmes étapes pour les champs personnalisés dans la fenêtre contextuelle d’édition en masse.

<figure><img src="../.gitbook/assets/en-image (196).png" alt=""><figcaption></figcaption></figure>

6. Cliquez sur **Enregistrer** pour enregistrer la configuration d’édition en masse.

<figure><img src="../.gitbook/assets/en-image (197).png" alt=""><figcaption></figcaption></figure>

### Résultat

Une fois la configuration enregistrée, un message de notification s’affiche.

<figure><img src="../.gitbook/assets/en-image (198).png" alt=""><figcaption></figcaption></figure>

## Modifier les données de mission en masse

1. Vérifiez le nombre de missions sélectionnées affiché dans la fenêtre contextuelle d’édition en masse.
2. Vérifiez la liste des champs sélectionnés lors de la configuration, affichée dans la fenêtre contextuelle d’édition en masse.
3. Choisissez les valeurs requises pour les champs de mission répertoriés.

<figure><img src="../.gitbook/assets/en-image (199).png" alt=""><figcaption></figcaption></figure>

4. Cliquez sur **Enregistrer**.

<figure><img src="../.gitbook/assets/en-image (215).png" alt=""><figcaption></figcaption></figure>

### Résultat

Toutes les missions sélectionnées sont mises à jour simultanément avec les valeurs choisies dans la fenêtre contextuelle d’édition en masse.

<figure><img src="../.gitbook/assets/en-image (201).png" alt=""><figcaption></figcaption></figure>

## Conseils

{% hint style="info" %}
**Vérifier avant d’enregistrer** : contrôlez le nombre de missions sélectionnées et la liste des champs sélectionnés dans la fenêtre contextuelle d’édition en masse avant de cliquer sur **Enregistrer**.
{% endhint %}
