# Filtrer le tableau à l’aide de critères

Filtrez le tableau des missions à l’aide de critères construits à partir d’une condition, d’un opérateur et d’une valeur. Les opérateurs disponibles dépendent du type de données.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à la page **Missions** et à son tableau des missions.
* Connaissez la condition, l’opérateur et la valeur sur lesquels vous souhaitez filtrer. Les opérateurs disponibles dépendent du type de données.

## Filtrer le tableau à l’aide de critères

1. Cliquez sur le **champ de saisie du filtre**.
2. Sélectionnez la condition appropriée parmi les suggestions.
3. Choisissez l’opérateur approprié dans le menu déroulant.
4. Saisissez la valeur requise pour la condition.
5. Appuyez sur la touche **Entrée** pour appliquer le filtre.

## Conseils

{% hint style="info" %}
**Choisissez l’opérateur selon le type de données** : les opérateurs disponibles dépendent du type de données. Consultez donc le tableau des opérateurs pour les valeurs alphanumériques, de date et arithmétiques avant de construire un critère.
{% endhint %}
