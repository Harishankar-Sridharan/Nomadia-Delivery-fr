# Modifier l’ordre des raccourcis de statut des missions

Modifiez l’ordre des raccourcis de statut des missions sur la page Missions afin qu’ils s’affichent dans la séquence de votre choix.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à la page **Missions**.

## Présentation de la fonctionnalité

* **Icône de configuration du filtre (panneau gris)** : ouvre la configuration dans laquelle vous organisez les statuts de mission.
* **Raccourcis de statut des missions** : les statuts que vous faites glisser dans la séquence de votre choix.
* **Enregistrer** : applique les modifications, uniquement pour la création d’un nouveau filtre.

## Modifier l’ordre des raccourcis de statut des missions

1. Cliquez sur l’**icône de configuration du filtre (panneau gris)**.
2. Faites glisser les statuts de mission dans la séquence souhaitée.

<figure><img src="../../.gitbook/assets/en-image (178).png" alt=""><figcaption></figcaption></figure>

3. Cliquez sur **Enregistrer** ou appliquez les modifications (uniquement pour la création d’un nouveau filtre).
