# Rechercher une mission

Recherchez une mission sur la page Missions à l’aide de l’un des différents champs.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à la page **Missions**.
* Ayez à disposition l’une des valeurs de recherche possibles, comme le numéro de mission, le code-barres de l’expéditeur, le numéro de téléphone, le nom du client, le code postal ou la ville.

## Présentation de la fonctionnalité

Vous pouvez effectuer une recherche à l’aide de l’un des champs suivants :

* **Numéro de mission**
* **Code-barres de l’expéditeur**
* **Numéro de téléphone**
* **Nom du client**
* **Code postal**
* **Ville**

## Rechercher une mission

1. Cliquez sur l’icône **Rechercher**.

2. Saisissez le **critère souhaité** dans le champ de saisie.
