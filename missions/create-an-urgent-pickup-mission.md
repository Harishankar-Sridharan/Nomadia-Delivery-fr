# Créer une mission de retrait urgente

Cette fonctionnalité permet d’insérer une mission de retrait imprévue dans un itinéraire existant et publié, alors que le livreur est déjà sur le terrain. Elle est spécifiquement conçue pour les scénarios de retrait, tels qu’un client demandant le retour immédiat d’un article endommagé.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès aux missions.
* Assurez-vous qu’un itinéraire existant et publié est disponible pour le livreur déjà sur le terrain.
* Connaissez les informations du retrait imprévu que vous devez insérer.

## Présentation de la fonctionnalité

* **Nouvelle mission de retrait** : mission de retrait imprévue que vous créez en premier.
* **Retrait d’urgence** : action du menu **Actions** qui insère le retrait dans un itinéraire existant.
* **Affecter après** : ajoute le retrait comme prochain arrêt.
* **À la fin** : ajoute le retrait à la fin de l’itinéraire actuel.
* **Remplacer** : bouton sur lequel vous cliquez lors de la dernière étape.

## Créer une mission de retrait urgente

1. Créez une **Nouvelle mission de retrait**.

<figure><img src="../.gitbook/assets/image (134) (1).png" alt=""><figcaption></figcaption></figure>

2. Sélectionnez la **mission** dans la liste.
3. Cliquez sur le menu **Actions**.
4. Sélectionnez **Retrait d’urgence**.

<figure><img src="../.gitbook/assets/en-image (135).png" alt=""><figcaption></figcaption></figure>

5. Choisissez le point d’insertion du livreur. Sélectionnez **Affecter après** pour ajouter le retrait comme prochain arrêt.

<figure><img src="../.gitbook/assets/en-image (136).png" alt=""><figcaption></figcaption></figure>

6. Vous pouvez également affecter **à la fin** pour ajouter le retrait à la fin de l’itinéraire actuel.
7. Cliquez sur **Remplacer**.

### Résultat

Ces missions regroupées seront exécutées une seule fois sur l’application mobile, ce qui réduit considérablement le temps d’exécution sur le terrain. De plus, même si les missions ne sont pas regroupées au préalable, l’application mobile regroupe automatiquement les missions qui partagent les mêmes informations d’adresse.
