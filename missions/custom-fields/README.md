# Champs personnalisés

Utilisez ces pages pour créer, organiser et appliquer des champs personnalisés dans Nomadia Delivery.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à l’onglet **Configuration**.
* Identifiez les objets auxquels vous souhaitez associer des champs personnalisés, tels que les missions, les sous-traitants ou les adresses.

## Présentation de la fonctionnalité

* **Création de champs personnalisés lors de l’importation** : ajoute dynamiquement de nouveaux champs pendant le processus d’importation, associés aux sous-traitants, aux missions ou aux adresses.
* **Hériter des données de mission depuis la liste des sous-traitants et des adresses** : initialise automatiquement les données des champs personnalisés lors de la création d’une mission, ce qui réduit la saisie manuelle.
* **Configuration de la visibilité des missions** : étend les restrictions de visibilité pour inclure des règles basées sur les champs personnalisés, en plus des contrôles basés sur l’agence.
* **Regroupement de champs personnalisés** : regroupe les champs personnalisés dans le formulaire de création de mission à l’aide d’un nom de groupe.
* **Codage couleur des champs personnalisés** : traité sur sa propre page, liée dans la liste ci-dessous.

## Conseils

{% hint style="info" %}
**Priorité d’héritage** : lorsqu’un champ personnalisé est initialisé à la fois depuis le sous-traitant et depuis la liste d’adresses, la valeur de la liste d’adresses est prioritaire sur celle du sous-traitant.
{% endhint %}

{% hint style="warning" %}
**Un seul champ de visibilité** : la visibilité des missions ne peut être activée que pour un seul champ personnalisé à la fois, et l’option n’est disponible que pour les champs personnalisés de type Liste de valeurs.
{% endhint %}
