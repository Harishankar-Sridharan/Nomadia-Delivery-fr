# Gérer le tableau des missions

Utilisez le tableau des missions pour personnaliser son affichage, le trier et le filtrer afin de trouver les missions dont vous avez besoin.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à la page **Missions** et à son tableau des missions.

## Présentation de la fonctionnalité

* **Menu Action du tableau** : ouvre **Actions - Personnaliser la liste** pour choisir les champs affichés dans le tableau.
* **Champs disponibles / Champs affichés** : les listes que vous utilisez pour sélectionner les champs qui apparaissent dans le tableau.
* **En-tête de colonne** : vous permet de trier le tableau par ordre **croissant** ou **décroissant**.
* **Liste déroulante du statut de mission ou bouton de raccourci** : filtre le tableau selon un statut, comme En attente ou Retiré.
* **Champ de saisie du filtre** : vous permet de sélectionner des conditions pour créer ou supprimer un filtre.
* **Icône Charger le filtre enregistré** : vous permet d’enregistrer un filtre sous un nom et d’épingler les filtres enregistrés.

## Personnaliser l’affichage du tableau

1. Cliquez sur le menu **Action du tableau**.
2. Cliquez sur **Actions - Personnaliser la liste**.

<figure><img src="../.gitbook/assets/Nomadia_Layout_V1 (5).png" alt=""><figcaption></figcaption></figure>

3. Sélectionnez les champs souhaités dans la liste des champs disponibles, puis cliquez sur l’icône de flèche pour les déplacer vers la section des champs affichés.
4. Cliquez sur **Enregistrer**.

<figure><img src="../.gitbook/assets/en-image (175).png" alt=""><figcaption></figcaption></figure>

### Résultat

Les champs sélectionnés sont affichés dans le tableau.

## Trier le tableau

1. Cliquez sur l’**en-tête de colonne** (par exemple, nom de famille).
2. Sélectionnez l’ordre **croissant** ou **décroissant**.

<figure><img src="../.gitbook/assets/en-image (212).png" alt=""><figcaption></figcaption></figure>

### Résultat

Le tableau se réorganise en fonction de la sélection.

## Filtrer le tableau à l’aide des raccourcis des statuts de mission

1. Cliquez sur la liste déroulante du statut de mission ou sur le bouton de raccourci.
2. Choisissez le statut souhaité, comme En attente ou Retiré.

<figure><img src="../.gitbook/assets/en-image (213).png" alt=""><figcaption></figcaption></figure>

### Résultat

Le tableau se rafraîchit et n’affiche que les entrées correspondantes.

## Créer un filtre

1. Cliquez dans le champ de saisie du filtre.
2. Sélectionnez la condition appropriée parmi les suggestions.
3. Cliquez sur l’icône Charger le filtre enregistré.
4. Saisissez le nom approprié dans le champ de saisie.
5. Cliquez sur **Enregistrer**.

<figure><img src="../.gitbook/assets/en-image (182).png" alt=""><figcaption></figcaption></figure>

## Épingler un filtre

1. Cliquez sur l’icône Charger les filtres enregistrés.
2. Cliquez sur l’icône d’épingle du filtre à épingler.

<figure><img src="../.gitbook/assets/en-image (183).png" alt=""><figcaption></figcaption></figure>

## Supprimer un filtre

1. Cliquez dans le champ de saisie du filtre.
2. Sélectionnez la condition appropriée parmi les suggestions.
3. Cliquez sur l’option de filtre.
4. Cliquez sur l’icône **Supprimer** pour supprimer le statut sélectionné.

<figure><img src="../.gitbook/assets/en-image (183).png" alt=""><figcaption></figcaption></figure>

## Conseils

{% hint style="info" %}
**Trouver les missions plus rapidement** : utilisez un raccourci de statut de mission pour n’afficher que les entrées correspondantes, et enregistrez un filtre sous un nom.
{% endhint %}
