# Ajout d’une mission

L’interface Ajouter introduit une expérience simplifiée de création de mission sur une seule page dans Nomadia Delivery. Elle est conçue pour réduire les étapes répétitives et améliorer la clarté. Elle remplace l’assistant traditionnel en plusieurs étapes par une vue unifiée qui rassemble en un seul endroit tous les paramètres, contraintes et dépendances de la mission.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à l’onglet **Configuration**.
* Identifiez le **Type de mission** et l’**Agence** pour lesquels vous souhaitez configurer la création de mission.
* Créez les champs personnalisés que vous souhaitez afficher dans le formulaire de mission, si vous prévoyez d’organiser des groupes de champs personnalisés.

## Présentation de la fonctionnalité

* **Regroupement des champs personnalisés** : les champs personnalisés peuvent désormais être regroupés sous un nom de groupe défini. Lors de la création d’une mission, ces champs sont affichés ensemble sous leur groupe respectif.
* **Ordonnancement des groupes** : les groupes de champs personnalisés peuvent être réorganisés par glisser-déposer lors de la création ou de la modification d’une configuration.
* **Tri des champs au sein des groupes** : les champs personnalisés peuvent être triés par Nom ou Identifiant pour un classement personnalisé.
* **Champs personnalisés pour les colis** : les champs personnalisés peuvent désormais être associés à des colis individuels lors de la duplication de missions.
* **Grouper les missions dans un conteneur** : les missions dupliquées peuvent être regroupées dans un conteneur parent.
* **Ajout immédiat de document** : la page Ajouter un document apparaît immédiatement après la création de la mission afin d’y joindre des documents.

## Organiser les groupes de champs personnalisés dans l’ordre souhaité

1. Lancez l’application Nomadia Delivery et cliquez sur l’onglet **Configuration** dans la barre de navigation supérieure.

<figure><img src="../.gitbook/assets/image (17) (1).png" alt=""><figcaption></figcaption></figure>

2. Dans Configuration, sélectionnez l’onglet **Missions**. Cette section affiche tous les paramètres liés aux missions.

<figure><img src="../.gitbook/assets/image (25) (1).png" alt=""><figcaption></figcaption></figure>

3. Cliquez sur le bouton **Actions** (en haut à droite ou dans la barre d’outils) et sélectionnez **Ajouter** pour créer une nouvelle configuration de mission.

<figure><img src="../.gitbook/assets/image (26) (1).png" alt=""><figcaption></figcaption></figure>

4. Sélectionnez le **Type de mission** approprié dans la liste déroulante.
5. Choisissez l’**Agence** correspondante à laquelle la mission s’applique.
6. Vérifiez les détails sélectionnés et cliquez sur **Suivant** pour accéder aux paramètres de configuration.

<figure><img src="../.gitbook/assets/image (27) (1).png" alt=""><figcaption></figcaption></figure>

7. Cliquez sur l’**icône Crayon (Modifier)** dans l’écran de configuration. Cela permet de modifier les champs et les paramètres d’affichage.

<figure><img src="../.gitbook/assets/image (29) (1).png" alt=""><figcaption></figcaption></figure>

8. Développez l’accordéon **Champs personnalisés**. Tous les groupes de champs personnalisés sont affichés sous forme d’accordéons séparés.
9. Cliquez sur un groupe pour le développer. Les champs appartenant à ce groupe sont listés.
10. Choisissez les champs requis à afficher (par exemple, adresse, contact, consignes de livraison). Le formulaire de mission se met à jour automatiquement en fonction des champs sélectionnés.

<figure><img src="../.gitbook/assets/image (29) (1).png" alt=""><figcaption></figcaption></figure>

11. Utilisez le glisser-déposer pour réorganiser les groupes de champs personnalisés et contrôler leur affichage dans le formulaire de création de mission.

<figure><img src="../.gitbook/assets/image (33) (1).png" alt=""><figcaption></figcaption></figure>

12. Pour modifier l’ordre des champs au sein d’un groupe, activez les champs à l’aide de l’identifiant ou du nom.

<figure><img src="../.gitbook/assets/image (34) (1).png" alt=""><figcaption></figcaption></figure>

13. Activez ou désactivez les champs obligatoires selon les besoins pour configurer les champs requis.

<figure><img src="../.gitbook/assets/image (35) (1).png" alt=""><figcaption></figcaption></figure>

14. Cliquez sur **Enregistrer** pour appliquer les modifications.

<figure><img src="../.gitbook/assets/image (36) (1).png" alt=""><figcaption></figcaption></figure>

Vous pouvez utiliser la même procédure pour activer des champs personnalisés pour les colis.

## Grouper les missions dans un conteneur

1. Ouvrez l’application Nomadia Delivery et accédez à l’onglet **Configuration**.
2. Accédez à l’onglet **Missions**.
3. Cliquez sur **Actions → Ajouter (bêta)**.
4. Choisissez le type de mission et l’agence, puis cliquez sur **Suivant**.
5. Cliquez sur l’**icône Crayon** pour modifier la configuration de la mission.
6. Dans **Regrouper vos colis**, sélectionnez l’une des options suivantes :
   * **Oui** : regrouper automatiquement les missions lorsque plusieurs colis sont ajoutés.
   * **Non** : ne pas regrouper les missions.
   * **Facultatif** : laisser l’utilisateur décider lors de la création de la mission.

<figure><img src="../.gitbook/assets/image (37) (1).png" alt=""><figcaption></figcaption></figure>

7. Si vous avez sélectionné **Oui**, choisissez le type de conteneur par défaut. Seuls les conteneurs agrégables sont affichés.

<figure><img src="../.gitbook/assets/image (38) (1).png" alt=""><figcaption></figcaption></figure>

8. Cliquez sur **Enregistrer** pour appliquer les modifications.

<figure><img src="../.gitbook/assets/image (36) (1).png" alt=""><figcaption></figcaption></figure>

## Ajouter des documents juste après la création de la mission

1. Ouvrez l’application Nomadia Delivery et accédez à l’onglet **Configuration**.
2. Accédez à l’onglet **Missions**.
3. Cliquez sur **Actions → Ajouter (bêta)**.
4. Sélectionnez le type de mission et l’agence, puis cliquez sur **Suivant**.
5. Cliquez sur l’**icône Crayon** pour modifier la configuration.
6. Activez le bouton **Ajouter des documents**.

<figure><img src="../.gitbook/assets/image (40) (1).png" alt=""><figcaption></figcaption></figure>

7. Cliquez sur **Enregistrer** pour appliquer les modifications.

<figure><img src="../.gitbook/assets/image (36) (1).png" alt=""><figcaption></figcaption></figure>

8. Lorsque le bouton est activé, le système vous invite à ajouter des documents immédiatement après la création de la mission. Ajoutez des documents depuis l’une des sources suivantes :
   * Ordinateur local
   * Bibliothèque de documents

<figure><img src="../.gitbook/assets/image (42) (1).png" alt=""><figcaption></figcaption></figure>

9. Cliquez sur **Enregistrer** pour joindre les documents.

<figure><img src="../.gitbook/assets/image (43) (1).png" alt=""><figcaption></figcaption></figure>

### Résultat

Les documents sont ajoutés avec succès à la mission.

<figure><img src="../.gitbook/assets/image (44) (1).png" alt=""><figcaption></figcaption></figure>
