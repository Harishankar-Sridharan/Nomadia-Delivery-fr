# Gérer les flottes de véhicules

Utilisez les pages de cette section pour gérer les véhicules et les flottes dans Nomadia Delivery.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à la page **Configuration**.
* Ouvrez **Gérer les véhicules** sous **Mes données** pour accéder à vos flottes et à vos véhicules.

## Présentation de la fonctionnalité

* **Gérer les flottes de véhicules** : importez, ajoutez et supprimez des flottes de véhicules.
* **Gérer les véhicules d’une flotte** : ajoutez, supprimez, exportez et colorez les véhicules d’une flotte, et personnalisez leur affichage.
* **Personnaliser les contraintes** : choisissez les champs de contraintes à afficher dans le tableau des véhicules.

{% hint style="warning" %}
**Suppression** : un message de confirmation (« Voulez-vous supprimer le véhicule ? ») s’affiche lorsque vous supprimez un véhicule ou une flotte de véhicules.
