# Glossaire

## Présentation

Les termes sont classés par ordre alphabétique. Chaque définition renvoie à la rubrique qui l’explique en détail.

## Termes

| Terme | Signification |
| ----- | ------------- |
| **Action personnalisée** | Un bouton qui appelle un système externe depuis un écran du back-office. Voir [Actions personnalisées](../custom-actions.md). |
| **Agence** | Une unité opérationnelle de votre organisation, comme un dépôt ou une succursale. Les missions, les utilisateurs et les tournées appartiennent à une agence. Voir [Gérer les utilisateurs](../manage-users/README.md). |
| **Article** | Un produit faisant partie d’une livraison et suivi avec la mission. Voir [Gérer les articles](../manage-articles/README.md). |
| **Carnet d’adresses** | Le référentiel des adresses clients que vous réutilisez lors de la création des missions. Voir [Gérer la liste globale d’adresses](../manage-global-address-list.md) et [Gérer la liste d’adresses](../contractors/manage-address-list.md). |
| **Champ personnalisé** | Un champ que vous ajoutez aux missions, aux adresses ou aux donneurs d’ordres pour enregistrer vos propres données. Voir [Champs personnalisés](../missions/custom-fields/README.md). |
| **Clé d’API** | Une clé secrète qu’un système externe utilise pour appeler l’API de Nomadia Delivery. Voir [Gestion sécurisée des clés d’API](../secure-api-key-management.md). |
| **Configuration de mission** | La disposition et les règles des formulaires de création et de modification des missions. Vous pouvez cloner une configuration, ou l’exporter et l’importer sous forme de fichier JSON. Voir [Configuration de la création des missions](../missions/mission-creation-configuration.md), [Cloner une configuration de mission](../missions/clone-a-mission-configuration.md) et [Importer et exporter des configurations de mission en JSON](../missions/import-and-export-mission-configurations-as-json.md). |
| **Configuration de visibilité du carnet d’adresses** | Un ensemble nommé de blocs du carnet d’adresses, comme la carte, les informations de contact ou les contraintes d’optimisation, que vous affectez à un profil utilisateur pour contrôler ce que voient ses utilisateurs. Voir [Visibilité des blocs du carnet d’adresses par profil utilisateur](../contractors/address-list-block-visibility-per-user-profile.md). |
| **Conteneur** | Une mission parente, comme une palette ou une boîte, qui regroupe plusieurs missions enfants. Voir [Gérer les types de conteneurs](../manage-container-types/README.md) et [Missions enfants de conteneur](../manage-container-types/container-child-missions.md). |
| **Cross-docking** | Un flux de missions où les marchandises transitent par un hub intermédiaire entre le middle mile et le last mile. Voir [Missions de cross-docking](../missions/cross-docking-missions.md). |
| **Dépôt** | Le bâtiment où les tournées commencent et se terminent, et où les marchandises sont stockées. Voir [Gérer les dépôts / bâtiments](../case-studies/mode-sans-itineraire/gerer-les-depots-batiments.md). |
| **Donneur d’ordres** | Le client qui commande les missions au transporteur. Voir [Sous-traitants](../contractors/README.md). |
| **Drop shipping** | Une mission livrée directement du fournisseur au client final, sans repasser par l’agence. Voir [Missions de drop shipping](../missions/drop-shipping-missions.md). |
| **eCMR** | La lettre de voiture électronique, l’équivalent numérique de la lettre de voiture CMR papier utilisée dans le transport routier. Voir [Accès à eCMR](../manage-document-templates/accessing-ecmr.md). |
| **Étude** | Un ensemble de zones et de secteurs utilisé pour organiser les territoires de livraison. Voir [Gérer les études et les zones](../manage-studies-and-zones/README.md). |
| **Export JSON** | Un fichier qui contient une ou plusieurs configurations de mission, que vous pouvez importer dans le même compte ou dans un autre compte. Voir [Importer et exporter des configurations de mission en JSON](../missions/import-and-export-mission-configurations-as-json.md). |
| **Feuille de chargement** | Le document qui liste ce qu’il faut charger dans le véhicule pour une tournée. Elle peut afficher la quantité prévue de chaque article par mission et son total pour la tournée. Voir [Agrégation des articles dans les feuilles de chargement](../manage-document-templates/article-aggregation-in-loading-sheets.md). |
| **Fil d’Ariane** | La barre en haut d’une page de configuration qui affiche le chemin vers la page. Chaque niveau situé au-dessus de la page actuelle est un lien. Voir [Navigation par fil d’Ariane dans la configuration](../configuration-breadcrumb-navigation.md). |
| **Flotte de véhicules** | Les véhicules utilisés pour les livraisons, avec leurs capacités et leurs contraintes. Voir [Gérer les flottes de véhicules](../manage-vehicle-fleets/README.md). |
| **Géocodage** | La conversion d’une adresse en coordonnées sur la carte. Voir [Améliorer le géocodage des adresses des missions](../missions/import-missions/improve-the-missions-addresses-geocoding.md). |
| **Groupe d’adresses** | Un ensemble nommé d’adresses du carnet d’adresses, comme **Lyon Retail**, que vous affectez aux donneurs d’ordres pour qu’ils puissent utiliser ces adresses dans leurs missions. Voir [Groupes d’adresses pour les donneurs d’ordres](../contractors/address-list-groups-for-contractors.md). |
| **Journal d’audit** | L’enregistrement des modifications effectuées sur la plateforme. Voir [Journaux d’audit](../missions/auditlogs.md). |
| **Journal de mission** | L’historique complet des activités effectuées sur une mission. Voir [Journaux des missions](../missions/journaux-des-missions.md). |
| **KPI** | Un indicateur clé de performance affiché sur la page d’accueil. Voir [Configurer l’affichage de mes KPI](../page-daccueil/configurer-laffichage-de-mes-kpi.md). |
| **Ligne d’ancrage** | La dernière ligne cochée ou décochée par un clic normal dans un tableau. Un Maj+clic sélectionne toutes les lignes de la ligne d’ancrage jusqu’à la ligne cliquée. Voir [Sélection d’une plage par Maj+clic](../missions/understanding-the-missions-page/shift-click-range-selection.md). |
| **Livreur** | Le chauffeur qui effectue les missions d’une tournée avec l’application mobile. Voir [Affectation automatique des missions aux livreurs](../manage-users/auto-assign-missions-to-deliverers.md). |
| **Logistique inverse** | Le flux des marchandises qui reviennent du client. Voir [Logistique inverse](../case-studies/reverse-logistics.md). |
| **Mission** | Un flux logistique de marchandises d’un point d’origine vers une destination, comme un colis ou une palette. Voir [Missions](../missions/README.md). |
| **Mission à étapes multiples** | Une mission suivie à travers plusieurs hubs et agences, de la collecte du first mile à la livraison du last mile. Voir [Missions à étapes multiples](../case-studies/multi-leg-missions.md). |
| **Mode Sans Itinéraire** | Un mode de travail centré sur la gestion et la traçabilité des missions, sans optimisation des tournées. Voir [Mode Sans Itinéraire](../case-studies/mode-sans-itineraire/README.md). |
| **Modèle de document** | Un modèle Word utilisé pour générer des documents, comme les feuilles de route, les étiquettes et les extraits de mission. Voir [Gérer les modèles de documents](../manage-document-templates/README.md). |
| **Modification en masse** | Une modification appliquée à plusieurs missions à la fois. Voir [Modifier en masse les données de mission](../missions/bulk-edit-mission-data.md). |
| **Navette** | Une ressource de transport qui déplace les marchandises entre les bâtiments. Voir [Gestion des navettes](../case-studies/mode-sans-itineraire/gestion-des-navettes.md). |
| **Nomadbot** | L’assistant virtuel de Nomadia Delivery. Voir [Nomadbot](../chatbot.md). |
| **Optimisation** | Le calcul qui construit les tournées à partir des missions, des véhicules et des contraintes. Voir [Optimiser les livraisons](../simulation/simulation-deliveries-optimize.md). |
| **Portail de réservation** | La page où les clients réservent ou reportent un créneau de livraison. Voir [Portail de réservation](../booking-portal/README.md). |
| **Pré-filtre** | Un filtre qui limite les missions chargées sur la page Missions. Voir [Pré-filtres](../missions/understanding-the-missions-page/pre-filters/README.md). |
| **Priorité** | L’urgence d’une mission. Voir [Prioriser une mission](../missions/prioritizing-a-mission.md). |
| **Profil utilisateur** | Un ensemble de droits d’accès partagé par plusieurs utilisateurs. Voir [Gérer le profil utilisateur](../manage-users/manage-user-profile.md). |
| **PUDO** | Un point de retrait et de dépôt où les colis peuvent être laissés lorsque le client est absent. Voir [Configuration PUDO](../case-studies/pudo-configuration/README.md). |
| **Réception** | Le contrôle des conteneurs reçus du terrain. Voir [Gestion des réceptions](../contractors/receptionmanagement.md). |
| **Retour au donneur d’ordres** | La création des missions de retour pour les colis qui n’ont pas pu être livrés. Voir [Retour au donneur d’ordres](../return-to-contractor.md). |
| **Sectorisation** | La création automatique de secteurs de livraison équilibrés. Voir [Créer des zones postales par gestion territoriale (sectorisation)](../manage-studies-and-zones/create-postal-zones-by-territory-management-sectorization.md). |
| **Sélection d’une plage** | La sélection d’un bloc de lignes consécutives d’un tableau par un clic puis un Maj+clic. Voir [Sélection d’une plage par Maj+clic](../missions/understanding-the-missions-page/shift-click-range-selection.md). |
| **Seuil d’alerte** | Une limite qui déclenche une alerte lorsqu’une valeur opérationnelle est dépassée. Voir [Gestion des alertes](../alertmanagement.md). |
| **Simulation** | Le résultat d’une optimisation des tournées, que vous vérifiez et ajustez avant de valider les tournées. Voir [Simulation](../simulation/simulation.md). |
| **Sondage** | Un formulaire que les livreurs ou les donneurs d’ordres remplissent à une étape de leur travail. Voir [Configuration de sondages personnalisés](../configuring-customized-surveys.md). |
| **Sous-statut** | Un statut détaillé qui décrit l’avancement ou le résultat d’une mission. Voir [Gérer les sous-statuts](../manage-substatus/README.md). |
| **Sous-traitant** | Un transporteur partenaire auquel le transporteur délègue des missions. Voir [Gestion des sous-traitants](../subcontractor-management/README.md). |
| **Statut** | L’étape d’une mission dans son cycle de vie, comme Créée, Chargée ou Livrée. Voir [Personnalisation des libellés de statut](../missions/customizing-status-labels.md). |
| **Tableau de bord personnalisé** | Un tableau de bord d’indicateurs que vous construisez et personnalisez. Voir [Tableaux de bord personnalisés](../custom-dashboards.md). |
| **Ticket** | Une demande ouverte au sujet d’une mission ou d’un colis entre donneurs d’ordres et transporteurs. Voir [Gérer les tickets](../manage-tickets/README.md). |
| **Tournée (itinéraire)** | La liste ordonnée des arrêts qu’un livreur effectue avec un véhicule. Voir [Itinéraires](../routes/README.md). |
| **Transporteur** | Le transporteur qui utilise Nomadia Delivery pour planifier et effectuer les missions de ses donneurs d’ordres. Voir [Introduction](../README.md). |
| **Type de conteneur** | Le type de conteneur, avec les règles d’héritage du statut, des attributs et des documents entre missions parentes et enfants. Voir [Modifier un type de conteneur](../manage-container-types/edit-a-container-type.md). |
| **Type de mission** | Le type de la mission, comme la livraison, la collecte, la visite ou le drop shipping. Voir [Visite – Un nouveau type de mission](../missions/visit-a-new-mission-type.md). |
| **Valider une tournée** | Confirmer les tournées d’une simulation pour qu’elles puissent être utilisées et publiées. Voir [Valider les itinéraires](../simulation/simulation-routes-validate.md). |
| **Visite** | Un type de mission pour une visite chez un client sans collecte ni livraison. Voir [Visite – Un nouveau type de mission](../missions/visit-a-new-mission-type.md). |
| **Vue Gantt** | Une vue chronologique des tournées et de leurs arrêts. Voir [Vue Gantt](../routes/ganttview.md). |
| **Zone de secours** | Un secteur secondaire temporaire utilisé lorsque le sous-traitant d’une zone principale n’est pas disponible. Voir [Création d'une zone de secours](../case-studies/creating-backup-zone.md). |
| **Zone postale** | Une zone de livraison définie par des codes postaux. Voir [Gérer les zones postales](../manage-studies-and-zones/manage-postal-zones.md). |
| **Zone principale** | Le secteur de livraison principal affecté à une équipe ou à un sous-traitant. Voir [Création d’une étude avec zone principale](../case-studies/study-creation-with-primary-zone.md). |
