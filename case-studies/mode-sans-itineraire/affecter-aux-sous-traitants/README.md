# Affecter aux sous-traitants

Configurez l’iFrame pour les sous-traitants et communiquez avec eux via l’interface externe intégrée lors de l’affectation de missions en mode Sans Itinéraire.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à la page **Missions**.
* Assurez-vous que votre entreprise utilise le mode Sans Itinéraire et dispose de sous-traitants auxquels vous affectez des missions.

## Présentation de la fonctionnalité

* **Configuration de l’iFrame** : personnalisez l’affichage des URL externes pour des utilisateurs sous-traitants spécifiques.
* **Interaction avec l’iFrame** : envoyez des mises à jour de statut et des messages aux sous-traitants via une interface externe intégrée, sans quitter l’application principale.

## Fonctionnalités

* [Configuration de l’iFrame](configuration-de-liframe.md)
* [Interaction avec l’iFrame](interaction-avec-liframe.md)

## Conseils

{% hint style="info" %}
**Configurez d’abord** : configurez l’**iFrame** du sous-traitant avant d’utiliser **Interaction avec l’iFrame** pour communiquer via l’interface externe intégrée.
{% endhint %}
