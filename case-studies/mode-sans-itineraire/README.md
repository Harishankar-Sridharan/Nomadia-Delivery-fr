# Mode Sans Itinéraire

Le mode Sans Itinéraire est conçu pour les entreprises qui privilégient la gestion des missions et la traçabilité plutôt que l’optimisation complexe des itinéraires. Ce mode simplifie l’interface utilisateur en masquant automatiquement toutes les fonctionnalités liées à la planification des itinéraires. Vous obtiendrez un flux de travail plus efficace, entièrement centré sur le suivi des missions de livraison.

## Avant de commencer

* Compte **Nomadia Delivery** actif.
* Profil utilisateur configuré pour l’accès Sans Itinéraire.

1. Connectez-vous avec vos identifiants de compte Sans Itinéraire.
2. Vérifiez que la barre de navigation affiche uniquement les modules essentiels tels que Accueil, Missions, Tableau de bord et Configuration.

<figure><img src="../../.gitbook/assets/noroute-noroute_timestamp_0_to_21 (2).png" alt=""><figcaption></figcaption></figure>

## Présentation de la fonctionnalité

* **Accueil** : accédez à l’interface de départ conçue pour les opérations quotidiennes.
* **Missions** : affichez et gérez les missions de livraison tout en suivant leurs emplacements.
* **Tableau de bord** : surveillez les données de performance opérationnelle et les statuts de mission.
* **Configuration** : gérez les paramètres système et les profils opérationnels.
* **Onglet Cartes** : visualisez les emplacements géographiques en temps réel de vos missions.
* **Onglet Détails** : consultez des informations spécifiques relatives à une mission sélectionnée.

## Suivre les missions

1. Sélectionnez le module **Missions** depuis le menu de navigation principal.
2. Cliquez sur l’onglet **Cartes** pour visualiser les emplacements des missions.
3. Appuyez sur l’onglet **Détails** pour inspecter les données spécifiques à la mission.

<figure><img src="../../.gitbook/assets/noroute-noroute_timestamp_1_to_20 (1).png" alt=""><figcaption></figcaption></figure>

## Conseils

{% hint style="info" %}
**Efficacité opérationnelle** : masquer les fonctionnalités de planification des itinéraires offre une interface plus claire pour se concentrer sur le suivi des missions.
{% endhint %}

{% hint style="warning" %}
**Limitations de la fonctionnalité** : notez que les onglets Simulation de route et Exécution ne sont pas disponibles en mode Sans Itinéraire.
{% endhint %}
