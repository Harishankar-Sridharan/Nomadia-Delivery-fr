# Gérer les types de conteneurs

La fonctionnalité Gérer les types de conteneurs permet aux responsables logistiques et aux répartiteurs de définir, configurer et gérer les différents types de conteneurs ou d’unités d’emballage utilisés dans les opérations de livraison. Cela aide à optimiser la planification de l’espace, à améliorer le suivi et à garantir une manipulation précise des marchandises pendant le transport.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à **Configuration**.
* Disposez du **Code** et de la **Traduction** du type de conteneur lorsque vous en créez un.

## Présentation de la fonctionnalité

* **Types de conteneurs par défaut** : le système prend en charge trois types de conteneurs par défaut : Carton, Palette et Colis.
* **Regroupement et quantités** : vous pouvez regrouper plusieurs conteneurs et suivre la quantité de chaque type de conteneur sur les sites clients afin d’améliorer la gestion des stocks et de la logistique.

## Créer un type de conteneur

1. Allez dans **Configuration**.

<figure><img src="../.gitbook/assets/image (58) (1).png" alt=""><figcaption></figcaption></figure>

2. Cliquez sur le menu **Configuration**.
3. Sous Personnalisation, cliquez sur **Types de conteneurs**.

<figure><img src="../.gitbook/assets/image (97) (1).png" alt=""><figcaption></figcaption></figure>

4. Cliquez sur le menu déroulant **Actions**.
5. Cliquez sur **Ajouter**.

<figure><img src="../.gitbook/assets/image (98) (1).png" alt=""><figcaption></figcaption></figure>

6. Saisissez le **Code** et la **Traduction**.

<figure><img src="../.gitbook/assets/image (99) (1).png" alt=""><figcaption></figcaption></figure>

7. Cliquez sur **Enregistrer**.

<figure><img src="../.gitbook/assets/image (100) (1).png" alt=""><figcaption></figcaption></figure>

### Résultat

Le type de conteneur est créé avec succès.

<figure><img src="../.gitbook/assets/image (101) (1).png" alt=""><figcaption></figcaption></figure>

## Modifier un type de conteneur

1. Allez dans **Configuration**.
2. Cliquez sur le menu **Configuration**.
3. Sous Personnalisation, cliquez sur **Types de conteneurs**.
4. Cliquez sur l’icône **crayon** du type de conteneur choisi.
5. Modifiez les informations selon les besoins.

<figure><img src="../.gitbook/assets/image (102) (1).png" alt=""><figcaption></figcaption></figure>

6. Cliquez sur **Enregistrer**.

<figure><img src="../.gitbook/assets/image (103) (1).png" alt=""><figcaption></figcaption></figure>

## Supprimer un type de conteneur

1. Allez dans **Configuration**.
2. Cliquez sur le menu **Configuration**.
3. Sous Personnalisation, cliquez sur **Types de conteneurs**.
4. Sélectionnez les types de conteneurs.
5. Cliquez sur **Actions**.
6. Cliquez sur **Supprimer**.

<figure><img src="../.gitbook/assets/image (104) (1).png" alt=""><figcaption></figcaption></figure>

### Résultat

Le type de conteneur est supprimé avec succès.

<figure><img src="../.gitbook/assets/image (105) (1).png" alt=""><figcaption></figcaption></figure>

## Conseils

{% hint style="info" %}
**Types de conteneurs par défaut** : le système prend en charge trois types de conteneurs par défaut : Carton, Palette et Colis ; vérifiez-les donc avant de créer un nouveau type.
{% endhint %}
