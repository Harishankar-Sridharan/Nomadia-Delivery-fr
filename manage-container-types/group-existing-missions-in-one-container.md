# Grouper des missions existantes dans un seul conteneur

Regroupez des missions déjà existantes sous un conteneur parent nouveau ou existant.

## Avant de commencer

* Connectez-vous à **Nomadia Delivery** avec un profil utilisateur ayant accès à la liste des missions.
* Assurez-vous que les missions que vous souhaitez regrouper existent déjà.
* Sachez si vous souhaitez un nouveau conteneur parent ou un conteneur existant, identifié par son ID.

## Présentation de la fonctionnalité

* **Regrouper dans un conteneur** : action du menu **Actions** qui regroupe les missions sélectionnées.
* **nouveau conteneur** : option qui crée un nouveau parent pour les missions sélectionnées.
* **ID du conteneur existant** : option permettant de sélectionner un conteneur existant par son ID.
* **Appliquer** : met à jour l’ID parent des missions sélectionnées.

## Grouper des missions existantes dans un seul conteneur

1. Sélectionnez la ou les missions destinées au regroupement.

<figure><img src="../.gitbook/assets/en-image (205).png" alt=""><figcaption></figcaption></figure>

2. Cliquez sur le menu **Actions**.
3. Sélectionnez **Regrouper dans un conteneur**.

<figure><img src="../.gitbook/assets/en-image (206).png" alt=""><figcaption></figcaption></figure>

4. Choisissez soit **nouveau conteneur** pour créer un nouveau parent, soit sélectionnez un conteneur existant par son ID.
5. Cliquez sur **Appliquer** pour mettre à jour l’ID parent des missions sélectionnées.

<figure><img src="../.gitbook/assets/en-image (207).png" alt=""><figcaption></figcaption></figure>

### Résultat

Les missions sont regroupées dans la mission parente.

<figure><img src="../.gitbook/assets/en-image (134).png" alt=""><figcaption></figcaption></figure>

## Conseils

{% hint style="info" %}
**Mise à jour de l’ID parent** : un clic sur **Appliquer** met à jour l’ID parent des missions sélectionnées ; confirmez donc que vous avez choisi le bon conteneur avant d’appliquer.
{% endhint %}
